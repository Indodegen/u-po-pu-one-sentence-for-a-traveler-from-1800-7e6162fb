One sentence that explains the modern internet to someone stepping out of the year 1800, built only from things they already know — a road, a post office, a library.

> Imagine every library and post office in the world joined by one road, so a letter you write arrives before its ink dries, and the book you ask for opens on your table.

## Run it

```sh
node main.ts
```

This reads `entry.txt` beside the program and writes it unchanged to `entry.txt` inside the output folder (`MAKEFUN_OUTPUT_DIR` when set, otherwise an `out` folder next to the program). It prints nothing.
